# UX Audit Dimensions

Use these dimensions for product and UX reviews:

1. Primary task clarity: Can the user tell what to do first?
2. Information hierarchy: Does visual weight match importance?
3. Cognitive load: Is too much required in working memory?
4. Interaction cost: Are common tasks visible or one click away?
5. Mental model fit: Is information grouped by user question, not backend structure?
6. Feedback and state: Are loading, empty, error, and success states clear?
7. Accessibility and responsiveness: Does the layout work across viewports and input methods?
8. Operational fit: Does the workflow support repeated real use?

Severity:

- `critical`: blocks the primary task or causes serious mistakes.
- `major`: slows or confuses common workflows.
- `minor`: polish or less common workflow issue.
- `enhancement`: useful improvement, not required.
