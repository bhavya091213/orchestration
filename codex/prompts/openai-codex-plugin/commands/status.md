# Codex Status

Run:

```bash
~/.codex/scripts/codex-status
```

Common forms:

```bash
~/.codex/scripts/codex-status --all
~/.codex/scripts/codex-status <job-id>
~/.codex/scripts/codex-status <job-id> --wait --timeout-ms 240000
```

Use this after starting `codex-review`, `codex-adversarial-review`, or `codex-rescue` with `--background`.
